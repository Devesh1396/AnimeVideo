# CET reel: illustrated video (v1 draft)

30-second (32 s) vertical reel for the free Calculation Efficiency Test, built from
`storyboard-illustrated/` with [Remotion](https://www.remotion.dev/). Every frame is code: SVG
illustration, animated per scene and timed to the voiceover's word timings.

Latest render: `renders/cet-reel-illustrated-v1.mp4` (1080×1920, 30 fps, H.264 + AAC).

## Layout

| Path | What it is |
|---|---|
| `src/timeline.json` | Scene start/end times, VO start times, music sections and SFX cues. Change timing here. |
| `src/scenes.ts` | One function per storyboard frame (S1a…S6b) returning that scene at time *t*. |
| `src/defs.ts` | Shared SVG: the cast (Aarav, classmates, Mom), red-pen marks, icons, gradients. |
| `src/styles.css` | Type, colours and layout, same as the storyboard (1cqw = 10.8 px). |
| `src/vo-timings.json` | Word timings for each VO line (written by `make_vo.py`). |
| `scripts/make_vo.py` | Draft Hindi voiceover (Microsoft Edge neural voice hi-IN-SwaraNeural) + word timings. |
| `scripts/make_audio.py` | Original music and sound effects synthesized in code, mixed with the VO, music ducked under the voice. Writes `public/audio/mix.wav`. |

## Rebuild

```bash
npm install
python3 scripts/make_vo.py      # only when the script changes (needs network)
python3 scripts/make_audio.py   # music + SFX + VO mix
npm run render                  # writes out/cet-reel-illustrated.mp4
npm run studio                  # live preview while editing
```

`npm run render` points Remotion at the Chromium that ships in this environment; drop the
`--browser-executable` flag to let Remotion download its own.

## Notes before publishing

- **Voice is a draft.** The Edge TTS voice is for timing and review only; for the final ad use a
  licensed TTS (e.g. Azure Speech, ElevenLabs) or a voice artist, then regenerate the mix.
- **Music and SFX** are generated by `make_audio.py`, so there is nothing to license.
- **Fonts** (Bricolage Grotesque, Kalam, Hind, Cinzel) are Google Fonts under the SIL Open Font
  License, stored in `public/fonts/`.
- **Guinness World Records emblem** is the client-supplied file; GWR requires a licence and its
  approval of each ad that uses it.
- **Remotion licence:** free for individuals and companies of up to 3 people; larger companies
  need a company licence (remotion.pro).
